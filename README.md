# LAYER AUTO / 레이어오토

가상 자동차 썬팅·광택·유리막코팅 전문점 포트폴리오. 실제 상담·예약·결제나 개인정보 수집을 하지 않습니다.

## 실행

Node.js 20 이상에서 `npm start` 후 http://127.0.0.1:4173 을 엽니다. 설치할 외부 의존성이나 빌드 과정이 없습니다. `npm test`로 견적 규칙을 검증합니다.

## 구성

- `index.html`: 첫 화면, 서비스, 시공 디테일, 계산기, 진행 과정, FAQ, 상담 시연
- `style.css`: 차콜 / 오렌지 디자인, 반응형 레이아웃, 모바일 하단 합계
- `estimate.js`: 견적 계산과 복사할 문장 생성
- `app.js`: 조건 선택, 실시간 요약, 상담 시연, 복사 및 접근성 처리
- `assets/`: ImageGen 생성 이미지 4장 및 SVG 파비콘
- `tests/estimate.test.js`: 제시한 예시와 등급·옵션·상담 예외 검증

## 계산 규칙

썬팅 기본비에만 필름 배수를 적용하며 차량 추가비, 제거비, 선루프에는 적용하지 않습니다. 차량 추가비는 선택한 각 서비스에 적용합니다. 광택+코팅 동시 선택 시 30,000원을 할인합니다. 승합·특수차량 및 특수 도장 상태의 광택은 숫자 총액을 표시하지 않고 상담 안내를 표시합니다. 미선택 서비스는 합계에서 제외합니다. 부가세 포함, 날짜·요일 할증 없음.

희망일은 한국 시간 기준으로 지난 날짜를 제한하고 예약 가능 여부나 확정 일정을 표시하지 않습니다. 클립보드가 차단되면 수동 복사 창을 제공합니다.

## 디자인 및 이미지

https://www.xpelkorea.com/ 의 대형 이미지, 굵은 제목, 간결한 메뉴와 섹션 구성을 참고했습니다. 원본 사이트의 사진·브랜드 자산·문구는 복제하지 않았습니다. 요청된 색상 `#151719`, `#222629`, `#F4F4F0`, `#FF793F`, `#AAB1B7`을 사용합니다.

폰트는 `Pretendard`, `Apple SD Gothic Neo`, `Malgun Gothic`, sans-serif 순의 시스템 폴백이며 외부 폰트 요청을 하지 않습니다. 이미지 생성 방식과 최종 프롬프트는 [ASSETS.md](ASSETS.md)에 기록했습니다. 모든 이미지는 연출 예시이며 실제 고객 시공 사진이 아닙니다.
